# VoiceTyper v2.1

Десктопное приложение для быстрого голосового ввода в любое активное окно Windows. Зажмите горячую клавишу, произнесите текст и отпустите её: распознанный текст вставится туда, где вы печатали.

Основной движок теперь локальный: **GigaAM v3 E2E RNN-T** распознаёт русскую речь на центральном процессоре и расставляет знаки препинания. Groq Whisper и Google Gemini сохранены как дополнительные облачные провайдеры.

## Возможности

- **Локальное распознавание по умолчанию**: без ключа API, подписки и оплаты запросов
- **Push-to-Talk**: зажмите `F8`, говорите, отпустите, текст вставится автоматически
- **Voice Activated**: запись начинается при появлении голоса и заканчивается после паузы
- **Быстрая работа на процессоре**: текущая сборка не использует видеокарту
- **Длинная диктовка без ожидания**: пока клавиша зажата, законченные фразы распознаются сразу, после отпускания остаётся только хвост
- **Обрезка тишины**: перед распознаванием убираются только тишина и слабый шум по краям записи
- **Очистка результата Groq**: известные отдельные выдуманные концовки удаляются без переписывания обычных предложений
- **Сохранение буфера обмена**: прежний текст возвращается после вставки транскрипции
- **История транскрипций**: до 500 записей
- **3 языка интерфейса**: English, Русский, Українська
- **Автозапуск с Windows** и цветовая индикация в системном трее

## Быстрый старт

1. Скачайте [`dist/VoiceTyper.exe`](dist/VoiceTyper.exe).
2. Запустите программу. Python и ключ API не требуются.
3. При первом запуске дождитесь готовности локальной модели.
4. Зажмите `F8`, надиктуйте текст на русском языке и отпустите `F8`.

Первый запуск требует подключения к интернету: программа скачивает около 230 МБ файлов модели. Они сохраняются в `%LOCALAPPDATA%\VoiceTyper\models` и используются при следующих запусках. После загрузки обычное локальное распознавание работает без сети.

Windows SmartScreen может показать предупреждение, потому что исполняемый файл не подписан платным сертификатом. Он собран из исходников этого репозитория.

## Как работает локальное распознавание

1. Пока нажата горячая клавиша, программа записывает монофонический звук с частотой 16 кГц.
2. Когда накопилось 20 секунд нераспознанного звука, Silero VAD делит его на фразы; фразы, за которыми прозвучала пауза от 1 секунды, распознаются сразу, ещё во время записи. Более короткие заминки фразу не режут.
3. После отпускания клавиши программа дожидается последнего блока микрофона и распознаёт только оставшийся хвост.
4. По краям хвоста обрезаются тишина и слабый фоновый шум.
5. Хвост до 23 секунд передаётся модели целиком, более длинный делится на речевые фрагменты.
6. Готовый текст собирается по порядку и вставляется в окно, которое было активно в момент начала записи.

Текущий локальный движок:

| Компонент | Значение |
|---|---|
| Модель | GigaAM v3 E2E RNN-T, русский язык |
| Сжатие | INT8 |
| Выполнение | ONNX Runtime, центральный процессор |
| Загрузка модели | Около 230 МБ вместе с определителем речи |
| Видеокарта | Не используется текущей сборкой |
| Сеть после загрузки | Не требуется для локального распознавания |

## Провайдеры

| Провайдер | По умолчанию | Ключ API | Сеть | Назначение |
|---|---:|---:|---:|---|
| Local GigaAM | Да | Нет | Только первая загрузка | Быстрая русская диктовка с пунктуацией |
| Groq Whisper | Нет | Да | Всегда | Дополнительное многоязычное облачное распознавание |
| Google Gemini | Нет | Да | Всегда | Дополнительное облачное распознавание |

Если выбран Local, но локальная модель недоступна, программа может использовать сначала Groq, затем Gemini, если соответствующие ключи уже сохранены. На новой установке без облачных ключей звук остаётся на компьютере.

## Настройки

| Параметр | Описание |
|---|---|
| Provider | Local, Groq или Gemini |
| API Key | Отключено для Local; ключи облачных провайдеров хранятся отдельно |
| Hotkey | Клавиша или комбинация Push-to-Talk; по умолчанию `F8` |
| Model | Фиксированная локальная модель или модель выбранного облачного провайдера |
| Language | Язык интерфейса, а не язык речи |
| Mode | Push-to-Talk или Voice Activated |
| Start with Windows | Запуск программы после входа в Windows |

Настройки, история и журналы хранятся рядом с исполняемым файлом. Облачные ключи записываются в файл настроек открытым текстом. Оставьте их пустыми, если используете только локальное распознавание.

Настройки версий 1.x один раз переводятся на Local без удаления сохранённых ключей Groq и Gemini.

## Сборка из исходников

Для Windows рекомендуется Python 3.13.

```powershell
py -3.13 -m pip install -r requirements.txt
.\build.bat
```

Сценарий сборки предпочитает Python 3.13, если он установлен, и создаёт `dist/VoiceTyper.exe`. Локальная модель не встраивается в исполняемый файл: она скачивается при первом использовании и проверяется по контрольным суммам.

Запуск тестов:

```powershell
py -3.13 -m unittest discover -s tests -v
```

## Что нового в v2.1

- Длинная диктовка распознаётся во время записи: законченные фразы обрабатываются, пока клавиша ещё зажата, и после отпускания текст появляется почти сразу (на записи в 133 секунды ожидание сократилось с 6,8 до 0,15 секунды при том же тексте)
- Модель занимает 4 потока процессора без холостого ожидания вместо всех ядер: скорость та же, а остальные программы не замирают
- Записи короче 20 секунд распознаются целиком, как раньше; живая нарезка режет речь только на паузах от 1 секунды, чтобы заминка внутри слова не давала обрывков
- Если живое распознавание не удалось, запись обрабатывается целиком, как раньше
- Добавлены тесты живого распознавания: закрытые фразы, открытый хвост, остановка перед вставкой и отказ

## Что нового в v2.0

- Локальная GigaAM v3 E2E RNN-T стала провайдером по умолчанию
- Добавлена автоматическая загрузка модели с проверкой контрольных сумм
- Добавлено деление записей длиннее 23 секунд через Silero VAD
- Исправлена потеря последнего блока микрофона после отпускания горячей клавиши
- Добавлены обрезка краевой тишины и отбрасывание полностью тихих записей
- Добавлено осторожное удаление известных выдуманных концовок Groq
- Для Groq установлена температура `0`, а при запасном вызове явно указывается русский язык
- Groq и Gemini сохранены как дополнительные облачные провайдеры
- Добавлены автоматические тесты подготовки звука, очистки текста и завершения записи

## Конфиденциальность

- Локальный режим обрабатывает звук на компьютере.
- При первом использовании файлы модели загружаются с Hugging Face.
- Звук отправляется облачному провайдеру только при его выборе либо при ошибке Local, если ранее был сохранён подходящий облачный ключ.
- История транскрипций сама по себе никуда не загружается.
